# SoundSky

SoundCloudの再生機能を使う、ジャケットを中心にしたChrome用プレイヤーです。落ち着いたオーディオ機器を意識した余白、サンセリフ体の曲名、ジャケット由来の背景、ライブのSoundCloud Queueを組み合わせています。

## 読み込み

ソースから初めて使う場合は、先に `npm ci` と `npm run build` を実行して `dist` を生成してください。

1. Chromeで `chrome://extensions` を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダの **dist** を選びます。
3. SoundCloudのタブをリロードします。
4. 下部操作バーの **SoundSky** ボタン、拡張機能のAction、または **Option/Alt + Shift + Y** で開きます。

戻るボタンまたはEscapeで通常画面に戻れます。Spaceで再生・一時停止、左右キーで5秒シークできます。シークと音量のスライダーはキーボードでも操作できます。ショートカットは `chrome://extensions/shortcuts` から変更できます。

配布ZIPには、初めて使う方向けの `START-HERE.txt` を同梱しています。設定画面の左上にSoundSkyのバージョンを表示します。

更新時は `npm run build` を実行し、拡張機能の管理ページでSoundSkyをリロードしてください。音声解析の接続を更新するため、開いているSoundCloudのタブもリロードしてください。

## 設定

SoundSkyの設定は、再生を続けたままサイドバーで開けます。「再生・見た目・サイト・SoundCloud設定」の4分類です。細かな光や動きの調整、次の曲の先読みは折りたたみを開いて変更できます。レコード効果がオフの間は、その速度調整も無効になります。

Light／DarkはSoundCloudに合わせます。SoundSkyだけのテーマ選択はありません。SoundCloud全体の着せ替えは追加設定としてオンにでき、全画面プレイヤーは着せ替えがオフでも使えます。通常のSoundCloud設定画面では、SoundSkyタブの項目も本家のフォームデザインで表示します。

設定は端末に自動保存し、別のSoundCloudタブにも反映します。保存できなかった場合はその旨を表示し、次の変更時に再試行します。公開前の継続利用・実環境確認の手順は [BETA-TEST.md](BETA-TEST.md) を参照してください。

## 実装

- Manifest V3、TypeScript、esbuild。装飾にはReactとPaperの公式シェーダーコンポーネントをローカルにバンドルしています。
- SoundSkyのUIはShadow DOMでページのCSSから分離しています。設定の「SoundCloud」タブで通常画面のテーマをオンにできます（初期状態はオフ）。横幅・下部操作部・角丸・文字を整え、再生中のジャケットからアクセントと背景の色を取ります。公式MeshGradientが通常画面の背景でも動きます。オフにすると元の見た目へ戻ります。
- SoundSkyの入口は通常の下部操作部の右端へ配置します。下部操作部が見つからない場合は従来の入口を表示します。
- 通常画面のテーマをオンにすると、下部操作部もSoundSky共通のアイコン・LiquidMetalの再生ボタン・MeshGradientのシークバーになります。ネイティブの音声エンジンと操作ハンドラーを維持し、位置表示だけを更新間で補間します。ドラッグ中はネイティブ表示を優先し、オフにすると装飾を外します。
- アルバム列はタッチパッドで横にスクロールでき、矢印は暗い背景と影で見やすくします。縦スクロールを横移動へ変換しません（Shift＋スクロールは横移動できます）。アーティスト画像は円形、アーティストのヘッダー画像は拡張後の横幅に合わせます。
- SoundCloudのページ用iframeにもテーマだけを適用します。音声解析やプレイヤーは複製しません。設定の通知は準備を確認した同一オリジンのフレームだけへ送り、Artist Toolsの埋め込みにも背景と配色だけを適用します。別オリジンやオリジンが不明なiframeへは送りません。
- 曲情報と状態はSoundCloudの下部プレイヤーから読み取り、操作はその現在曲専用の操作部へ接続します。独立した音声プレイヤーは作りません。
- QueueはSoundCloudの実DOMを元の位置に保ち、SoundSkyの領域へ表示します。仮想スクロール、曲の選択、AutoPlayはSoundCloud本体が管理します。最初に現在曲へ合わせ、上へスクロールした履歴は薄く表示します。
- Likeは現在曲、Followは現在アーティストの下部プレイヤー専用ボタンを使います。Repostは現在曲のQueue項目が所有するメニューを検証し、SoundCloudのRepost操作を表示します。対象が確認できなければ無効になります。
- 再生状態のDOM監視は再生UIの範囲に限定します。通常画面のテーマがオンの時は、ページ遷移によるアルバム列の追加も監視します。プレイヤーを開いている間の状態確認は4回/秒、ルートの交換確認は単一セレクタで2秒ごとです。
- 背景は32×32に縮小したジャケットを使い、最大640×360・10fpsのWebGLで描画します。閉じた時、タブが非表示の時は停止します。Reduced Motionでは静止画、WebGLが使えない時はCSS背景に切り替わります。
- Liquid Metalは再生ボタンに使用し、再生・一時停止マークはマスク内の背景を明度反転します。Heatmapは以前のカバー直下の角丸面へ配置し、カバーより6〜10pxだけ大きく表示します。ジャケット画像はシェーダーへ渡しません。空色の波は公式シェーダーのアニメーションで流れ、赤い熱は音量に応じて上から下へ広がります。「周囲の光」設定の「カバー周囲の光」でオン／オフを切り替えられます。
- 金属の流速は生の音声RMSと帯域の立ち上がりに連動します。Heatmapは設定した速度で動きます。音量の正規化・圧縮・速度の平滑化や上限は入れていません。停止中・非表示時・Reduced Motionではアニメーションを停止します。
- カバーは音量とスペクトルの変化に連続的に反応し、標準の拡大上限は15%です。音圧の高い曲でも拡大上限に張り付きにくい配分に変更しています。SoundCloudのWeb Audio出力から並列の解析枝へ接続し、通常の出力接続は維持します。Heatmapは元の固定サイズと質感を保ち、カバーだけが拡大します。解析値の保存や送信は行いません。検出方式と調査先は [AUDIO-NOTES.md](AUDIO-NOTES.md) に記載しています。
- 音量はドラッグ中に反映され、シークバーはフレームごとの補間で滑らかに動きます。
- 再注入や拡張機能リロード時には、以前のインスタンスのObserver・タイマー・スタイルを解放します。

## プライバシー

権限は `activeTab`、`scripting`、見た目の設定を端末に保存するための `storage` です。コンテンツスクリプトの対象はSoundCloudのHTTPSページのみです。

設定はChrome拡張機能のローカルストレージに保存します。SoundSky独自のサーバー、分析サービス、外部JavaScriptの読み込み、利用ログの保存・送信はありません。

先読みが有効な場合は、SoundCloudのページと既存のAPI通信から再生情報をタブ内で一時参照し、SoundCloud API・許可された音声配信先・SoundCloud画像CDNへ追加の読み込みを行います。認可情報はSoundCloud APIへの通信のためにタブ内のメモリで扱い、SoundSkyのUI・音声CDN・独自サーバーには送信しません。Cookieやブラウザーのログイン情報を直接読み出す機能はありません。

先読み音声は最大24MiB・有効期間15分のメモリ上のキャッシュです。先読みをオフにすると音声キャッシュを破棄します。再生情報を含むタブ内の一時データは、タブ終了・ページ再読み込みで破棄されます。完全なオフライン再生を保証する機能ではありません。通常の再生・アカウント操作の通信はSoundCloud本体が行います。

## 開発と検証

```sh
npm install
npm run check
npm test
npm run build
npm run package
```

型検証・テスト・配布ビルドをまとめて確認する場合は `npm run verify` を実行します。ビルドは別の作業フォルダーで生成・検証してから `dist` を置き換え、失敗時は直前のビルドを維持します。ZIPも検証が完了してから置き換えます。`npm run verify:package` で既存ZIPと現在のビルドの内容を照合できます。

`npm run dev` で `http://127.0.0.1:4173` にローカル検証画面を起動できます。`/responsive` には画面サイズ切り替え用の検証画面があります。これらはレイアウトとフォールバックの検証用で、実SoundCloudでの動作証明を代替しません。

現在の実環境テスト状況は [TEST-REPORT.md](TEST-REPORT.md) を参照してください。

ビジュアルの標準設定は、カバー拡大15%、反応感度3.0×、背景速度0.1×、金属の速度2.8×、カバー周囲のHeatmap速度1.0×です。「すべて標準に戻す」で標準値に戻せます。保存済みの調整値は引き継ぎます。

背景のMeshGradientにはPaperの公式コンポーネントを使用します。カバーから最大3色を抽出して暗い4色の配色へ整え、曲変更時は約0.9秒で色相を滑らかに移します。単色・同系色・白黒・画像なしでは用意した配色へ切り替わります。音量が大きいほど明るく、音量と立ち上がりに応じて速く動きます。操作部分の土台は暗いGemSmoke、シークバーは細い幅に合わせたMeshGradientの光です。新しい動く装飾は停止・非表示・閉じた時とReduced Motionで静止します。カバー周囲のHeatmapはPaperの公式シェーダーを使用します。

カバーの角丸も拡大率に合わせて増減します。設定はカバー / 周囲の光 / 背景 / 操作部分に分け、カバーの拡大と感度、カバーHeatmapのオン／オフ、赤い光の反応、光の速度、金属の速度、背景の速度と明るさ、煙とシークの速度を個別に調整できます。上限は拡大30%、感度12×、Heatmap・金属・背景の速度8×です。

設定名と説明は日本語です。スライダー下の「標準」を押すとその項目だけ戻せます。「すべて標準に戻す」は全項目を戻します。変更はすぐに反映され、自動保存されます。周囲の光をオフにすると関連する調整は無効になります。

カバーは打音の判定で反応を選別せず、生の音量とスペクトルの変化を足して動きます。通常域（拡大上限の80%まで）は入力に比例します。上限付近では直近500msの音の平均に対する細かな増減を、上限近くの動きとして表示します。一定の音を時間経過だけで縮める処理はありません。持続音でも持ち上がり、音が弱くなればそのまま下がります。シェーダーへ渡す音声解析値にはこの処理を適用しません。

「背景」の「画面のゆらぎ」で、最大各方向約14pxの揺れを調整できます。ランダムな地点の間を普段は約5秒かけて移動します。キックなど低音の立ち上がりで移動が加速し、次々の地点を通りながら徐々に通常の速さへ戻ります。地点間は滑らかな曲線でつなぎます。初期値はオフです。再生停止で元の位置へ戻り、Reduced Motionでは止まります。Queueも同じ位置変化に追従します。

GitHub Actionsで型検証、Nodeテスト、配布パッケージ生成を実行します。実曲検証の対象は [tracks.json](docs/verification/tracks.json)、見た目の比較基準は [基準画像の説明](docs/baselines/1.2.18/README.md) に記録しています。

背景シェーダーは親ページに集約し、埋め込みページではテーマとアクセントを継承します。所有するシェーダーを破棄する際はWebGLコンテキストも明示的に解放します。

## 1.3.10

「SoundCloudの見た目を整える」がオンの時、通常の曲・プレイリストページの大きなカバーも音に合わせて拡大します。SoundSkyと同じ拡大上限・感度と生の音量への反応を使い、拡大時には角丸も調整します。曲ページは再生中の曲と一致する時、プレイリストページは実際の再生元と一致する時に反応します。埋め込みの新しい曲ページも対応し、別のプレイリスト・アーティストのアイコンには適用しません。停止・ミュートで縮小し、テーマオフ・SoundSky表示・動きを減らす設定では元のスタイルを復元します。


## 1.3.11

通常画面で再生中の曲・アルバムのカバーを、ホーム・タグ一覧・プレイリスト内でも音に合わせて拡大します。ホームのシステムプレイリストも再生元で照合します。遅れて読み込まれたカードにも適用し、別の曲・再生元には適用しません。

通常操作部の再生／一時停止ボタンは、SoundCloudがボタンを更新しても同じ金属シェーダーの描画面を保持します。停止時はその場で静止し、再開時は続きから動きます。更新直後にも金属の土台を維持し、アクセント色の点滅を防ぎます。

## 1.3.12

設定 → 操作部分 →「レコードのように再生・停止」で、音程と速度が変わる再生／停止効果をオン・オフできます。初期値はオフ。オンの場合、停止は約0.42秒で減速してからネイティブの停止を実行し、再生は約0.24秒で通常の速さへ戻ります。SoundSky・通常画面の下部再生ボタン・Spaceに対応。減速中の再操作は加速へ反転します。シーク・曲変更・設定オフ・破棄では遅延した停止を取り消し、元の速度とピッチ補正へ復元します。

通常画面とNext Upのカバーの角丸は、画像の大きさに比例する3%へ変更しました。再生中の小さなカバーも、拡大率を反映しつつサイズに合わせた角丸になります。アーティスト画像は円形を維持します。

## 1.3.13

設定 → 操作部分 →「次の曲を先読み」で、オフ／1曲／2曲／3曲を選べます。標準は3曲・曲全体です。「各曲の読み込み量」で冒頭15秒／30秒／1分／2分／曲全体も選べます。音声のセグメント単位で区切るため、指定時間を少し超えて読み込む場合があります。Next Upで確定した再生順に従い、次の曲の音声・再生用リスト・初期化データをタブ内で一時保存します。シャッフル時も実際のキュー順を使います。次の曲が未確定のAutoPlayでは先読みしません。

保存済みの音声は再生時に再利用し、その曲が現在の曲になっても残します。現在の再生の通信が始まると先読みを中断し、通信が落ち着いてから再開します。音声データの保存上限は24MiB、有効期間は15分。オフ・タブの終了・再読み込みで破棄します。全データを取得できた曲だけ「音声を準備済み」と表示します。曲が大きい場合や対応しない形式では準備を完了できない場合があります。

SoundCloudの再生権限の確認を維持します。認証通信や未取得のデータはネット接続が必要で、完全なオフライン再生を保証する機能ではありません。新ビルドでの実SoundCloud検証は再読み込み後に行います。


## 1.3.14

AutoPlayが有効でも、Next Upに確定した次の曲があれば先読みします。一時停止中にも準備を進めます。現在のSoundCloudが使うplayback.media-streaming.soundcloud.cloudの音声配信へ対応し、準備が0曲のままになる問題を修正しました。取得できない曲が一つあっても、残りの曲の準備を続けます。
